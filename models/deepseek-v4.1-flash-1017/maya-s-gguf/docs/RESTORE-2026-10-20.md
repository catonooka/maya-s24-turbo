## Pack rebuild — fully local, no downloads
`/opt/dsv41/pack/prepare_pack.py` (inside the d141 image) regenerates
`DSV41-EXL3-3090-local` from the two local dirs:
- symlinks the 43 EXL3 safetensors + k-map from the 2.9bpw source
- engram keys (4): layers.{1,14}.engram.embed.{weight,scale} -> engram shards
- rewrites config.json (DeepseekV41LLMForCausalLM, exl3 quant block)
- reconstructs the FP16 `wo_a` overlay (43 groups x 8 slices, 8192x4096) on
  GPU via pinned EXL3 math -> 43 safetensors, total ~2.7G
- writes host-plan.json (40 layers x 384 experts) + adapter-receipt.json

Ran 2026-10-20, ~18s on GPU0, clean exit: 235 dense modules, 190,900 weight
names, receipt `dense_quant_modules=235 weight_names=190900`.

Rebuild command (in shell history pattern):
```
docker run --rm --gpus "device=0" --shm-size 8g --cap-add IPC_LOCK \
  --ulimit memlock=-1 -v ~/models:/models \
  --entrypoint /bin/bash ghcr.io/0xsero/dsv41-flash-offload:d141-main -c \
  'python3 /opt/dsv41/pack/prepare_pack.py \
     --source /models/DeepSeek-V4.1-Flash-1017-EXL3-2.9bpw \

     --out     /models/DSV41-EXL3-3090-local'
```

### Two extra steps required for OUR 2.9bpw source (not needed for Mia D010)
prepare_pack.py assumes the campaign's uniform-3.0bpw Mia source. Our local
2.9bpw quant differs in two ways; both fixes are local-only:

1. `expand_native_dense.py` (second image script, must run after prepare_pack):
   expands `attn.compressor.wkv/wgate` + `attn.indexer.wk` EXL3 groups to
   FP16 `native-dense.safetensors` — else loader rejects bits=8 indexer
   (`unsupported non_routed_exl3 layers[...indexer.wk] bits=8`).
   ```
   docker run --rm --gpus "device=0" ... -c 'python3 \
     /opt/dsv41/pack/expand_native_dense.py \
     --pack /models/DSV41-EXL3-3090-local \
     --source /models/DeepSeek-V4.1-Flash-1017-EXL3-2.9bpw'
   ```
2. `src/drop_bias_vl.py` — our source carries 43 VL `ffn.gate.bias_vl` keys
   that the `--language-model-only` loader has no params for (KeyError).
   Drops them from the pack index. (Mia D010 didn't carry these keys.)
3. Mixed-K `layer_bits` — our quant is sensitivity-allocated MIXED-K
   (K2 layers 18-22, K3 0-17+23-39, K4 MTP 40-42; hist 35x3/5x2/3x4),
   NOT uniform 3.0. prepare_pack wrote only `{40..42: 4}`. Loader died with
   `EXL3 load shape mismatch layers.18...w13_trellis dest(320,144,48) !=
   loaded(320,144,32)`. Fix: scanned true K per layer from w1.trellis shape
   (`shape[-1]//16`) and wrote the full map into both config.json and
   quantization_config.json `layer_bits`.
   NOTE: pack files are root-owned after docker runs — `sudo chown -R
   user:user` the pack dir before host-side edits.
